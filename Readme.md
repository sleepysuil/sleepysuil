## Featured Project

### Alumni Monitoring and Tracer System
**Capstone Project** &nbsp;|&nbsp; PHP · MySQL · JavaScript · HTML · CSS

A web-based platform that enables an educational institution to stay connected with its graduates and monitor their career outcomes. The system replaces scattered paper surveys and spreadsheets with a single, centralized source of truth.

**Key Features**
- **Centralized Alumni Records:** a searchable database of graduates and their profiles
- **Online Tracer Surveys:** alumni submit and update employment and career information
- **Reports & Analytics:** employment data summarized to support administrative decisions
- **Role-Based Access Control:** secure, separate interfaces for administrators and alumni

**Impact:** Institutions rely on accurate graduate employment data for accreditation and program improvement. This system makes collecting, managing, and reporting that data faster, more accurate, and more accessible.
